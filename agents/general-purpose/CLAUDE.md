# General Purpose — Instrucciones de uso

**subagent_type:** `general-purpose`

## Propósito

Agente polivalente para investigación compleja, búsquedas multi-paso y tareas que combinan varias herramientas.

## Cuándo usar

- Por defecto cuando no aplica un agente más específico
- Investigación que requiere múltiples rondas de búsqueda o herramientas
- Tareas que combinan lectura de archivos, web y ejecución de comandos

## Cuándo ceder el paso

- Desarrollo de software → ADA
- Entrenamiento → FORGE
- Solo localizar código → Explore
- Diseñar plan de implementación → Plan
