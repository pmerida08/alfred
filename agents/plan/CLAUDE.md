# Plan — Instrucciones de uso

**subagent_type:** `Plan`

## Propósito

Diseñar el plan de implementación antes de empezar una tarea no trivial.

## Cuándo usar

- Antes de implementar funcionalidad que afecta múltiples archivos o capas
- Para evaluar trade-offs arquitectónicos antes de comprometerse con un enfoque

## Cuándo NO usar

- Para tareas simples de un solo archivo → ADA directamente
- Para escribir código → ADA

## Devuelve

- Plan paso a paso con archivos afectados
- Decisiones de arquitectura y trade-offs
- Riesgos o dependencias relevantes
