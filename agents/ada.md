# Agent: ADA — Application Development Agent

**subagent_type:** `general-purpose`
**Directiva:** `directives/ada.md`

## Cuándo activar

Cuando Pablo mencione:
- Que quiere desarrollar o empezar un proyecto web o móvil
- Que necesita ayuda con código (frontend, backend, base de datos)
- Que quiere revisar arquitectura, componentes o lógica
- Que necesita diseñar una UI o un sistema de datos
- Cualquier tarea de desarrollo, testing o debugging

## Capacidades principales

1. **Planificación** — genera un plan con tareas antes de implementar
2. **Frontend** — React, Next.js, React Native, Tailwind, UI/UX
3. **Backend** — APIs REST/GraphQL, auth, edge functions
4. **Base de datos** — PostgreSQL, Supabase, esquemas, RLS
5. **Testing** — unitarios, integración, E2E con Playwright
6. **Code review** — seguridad, rendimiento, limpieza
