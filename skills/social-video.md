# Skill: social-video

**ID:** `social-video`
**Cuándo:** Pablo quiere generar el material audiovisual real de una pieza — un clip de vídeo corto (Short/Reel/TikTok), una imagen, portada o miniatura a partir de un guion o idea.

Carga HERALDO (`agents/heraldo/CLAUDE.md`) y ejecuta la directiva `agents/heraldo/directives/social-video.md`.

> Usa el MCP de generación multimedia (Higgsfield): `generate_video` / `generate_image`. **Consume créditos (dinero real): HERALDO confirma prompt, modelo y coste antes de generar.** Nunca publica: entrega el fichero y Pablo publica. En Telegram, el render va a `.tmp/heraldo_outbox/`.
